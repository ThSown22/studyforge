# DevOps readiness V2

Hiện có Dockerfile riêng frontend/backend và Compose gồm PostgreSQL 17, migration job, backend, frontend. `compose.yaml` phục vụ development và integration test local; production sau này sẽ inject HTTPS, secrets và resource policy bằng Kubernetes thay vì dùng nguyên cấu hình local. Backend `npm ci` từ lockfile riêng; Node 22 dùng native TypeScript stripping để build. Image runtime chứa code build và dependency runtime, không chứa `.env`. PostgreSQL dùng named volume; `depends_on` chờ DB healthy và migration thành công. Health endpoint truy vấn DB. Cấu hình DB, port, origin và dictionary key được inject lúc chạy; không build key vào image.

Profile `qa` có smoke test chạy trong container, đi qua frontend proxy và kiểm tra auth → collection → lưu từ không trùng → trạng thái → review event, rồi dọn dữ liệu test. Ngày 25/10/2026, người dùng đã chạy thành công `docker compose --profile qa run --build --rm smoke` và nhận kết quả `V2 Compose smoke test passed: proxy, PostgreSQL, auth, collections, duplicate save, status, review.`

**Đã kiểm tra:** `docker compose --env-file .env.example config --quiet`, Node syntax/import checks, unit tests V2 và Compose smoke test có build thực tế. Smoke test xác nhận frontend proxy, backend, PostgreSQL, auth/session, tạo collection, quy tắc duplicate save, cập nhật trạng thái, review queue/event và stats hoạt động cùng nhau. Kết quả Docker là bằng chứng do người dùng chạy ngoài sandbox Codex. **Chưa kiểm tra:** persistence qua container restart, migration trên database đã có dữ liệu, backup/restore volume, browser QA responsive/screenshot và Dictionary API thật.

Trước khi triển khai GitLab Runner/Harbor/Kubernetes/Helm cần: test migration trên DB đã có dữ liệu và persistence qua restart; browser smoke/responsive QA; quy trình backup/restore volume; HTTPS và `SECURE_COOKIES=true` ở production; secret injection từ nền tảng triển khai; pin image bằng digest/CI tag; tài nguyên/observability; license cho dữ liệu từ điển. Những phần CI/CD/Kubernetes chưa triển khai trong phase này.
